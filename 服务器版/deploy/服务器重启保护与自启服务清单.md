## 三、依赖关系（本机内）

```
nginx:8123 ──/api 反代──> certagent.service:8125
                          (后端跑在 127.0.0.1)
```

- nginx 挂了 → 前端 502（后端可正常）
- certagent 挂了 → 前端在但接口失败 → `Restart=always` 自动拉起

## 四、重启保护建议（断电后能自动恢复，无需值守）

两个服务处于 enable + Restart 状态，断电重启后通常能自己回来。两个可选加固，都是为了**避免开机竞态**（网络还没就绪服务就启动）：

```ini
# /etc/systemd/system/certagent.service 加固（可选）
After=network-online.target
Wants=network-online.target
RestartSec=8
```

改完：

```bash
sudo systemctl daemon-reload
sudo systemctl restart certagent
sudo systemctl enable certagent
```

nginx 同理一般无需改动（系统服务自带）。

## 五、节前自检命令

```bash
systemctl --failed --no-legend                          # 应无 failed
systemctl status certagent nginx --no-pager | head -20  # 两个都是 active(running)
curl -s -o /dev/null -w '8123 %{http_code}\n' http://127.0.0.1:8123/
curl -s -o /dev/null -w '8125 %{http_code}\n' http://127.0.0.1:8125/health
ss -tlnp | grep -E '8123|8125'
```
