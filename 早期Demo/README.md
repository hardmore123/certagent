# 早期Demo（report-verify-demo 初版）

来源：工作区 `report-verify-demo/`，项目二的**初版简化 Demo**。

## 角色
项目二的早期原型，对应需求 "5. 确认报告草稿准确性"。复用了 `list-merge-demo` 的解析内核（.doc 转换、表格 gridSpan/vMerge、表头映射），新增了报告结构定位、Word 批注写入、核对语义比对。

## 与主代码关系
这是**早期简化版**，后来演进为 `主代码/`（报告草稿准确性核对/）的完整版。主代码是当前正式版本，本 Demo 仅作历史参考（看演进脉络与最初设计）。

## 架构（初版）
```
CLI(cli.py) → pipeline → parser(定位关键件清单表) → differ(核对) → writer(批注+汇总)
```

## 已知限制（初版未完善）
1. 安全/EMC 清单分块按"出现顺序"粗判，未读段落标题精确定位
2. 同一匹配键多行只取首行代表，未做多行精细配对
3. 批注锚点按逻辑列号近似定位，复杂合并单元格可能偏移
4. 尚未接入 Web 任务/确认页与多轮审批闭环

完整版（主代码）已解决以上全部限制。
