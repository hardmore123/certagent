# 认证智能体 · 项目整体梳理

> 依据《20.认证智能体PRD》第六章功能详细说明 + 第九章 IT 系统依赖整理
> 用途：看清全项目任务边界、核心能力、要攻克的核心难点、对外依赖与需沟通的接口

---

## 一、项目一句话定位

面向认证全生命周期（数据 → 资料 → 审批 → 获证 → 预警），用 AI 智能体替代人工的资料准备、文档核对、证书管理、联网查询等环节，实现"提质提效 + 防一致性检验不合格"。预估节省约 8000 人工时。

## 三、各任务需求要点（补充说明）

- **1 认证申请单**：产品包发布后一键生成草稿，只保留报备型号等少数人工项；前提是产品包结构化/规格书单独存放（依赖项目管理智能体）。
- **3b 清单整合（已选为首个 MVP）**：两份 Word→整合清单+对照表，详见《需求说明_变更开发清单整合》。
- **3d 物料扩点**：链路最长最难——PLM 反查机型→筛在产机型→逐机型翻 PDF 认证报告查是否已报备拟扩点供方→输出未报备清单+简化备案评估表。PRD 明确"PDF 解析准确率"为技术难点。
- **4c 电源板差异比对**：需按 BOM 位号级比对组件物料，输出 TOP5 最接近组件，规则复杂。
- **5 审批比对**：以认定工程师的零部件认证信息库为基准，(名称+型号+规格)为键逐项比对，含 interchangeable 四种规则。
- **6 报告草稿核对**：输出要"两种标识"（草稿内批注 + 顶部 1/2/3 汇总差异）。已有类似内部系统 doc-verification 可参考。
- **7 归档管理**：本质是打通 云盘/档案室/PLM 三处的自动同步 + 有效期预警 + 自动延期申请。
- **8b 证书有效性查询**：逐条证书号去 5 个官方网站查存续状态，多站点需验证码或账号——自动化难点。

## 四、核心点总结

### 全项目可抽象为 5 类核心能力

| 能力 | 涉及任务 | 说明 |
|---|---|---|
| **A 对比/核对** | 3a,3b,3d,4a,4c,5,6,8a | **出现频率最高、最核心的主线能力** |
| B 抓取+自动填充 | 1,4b | 从 PLM/BOM/规格书抓字段 |
| C 文档生成 | 3b,3d,4b,10 | 清单/对照表/评估表/声明/铭牌 |
| D 归档+生命周期管理 | 7 | 归档同步 + 有效期预警 |
| E 联网查询+看板 | 8b,11 | 外部网站查询 + 数据聚合 |

### 需要解决的核心点：是"检查对比"，但底座是"文档结构化解析"

- **是的，"检查对比/核对"是贯穿最多环节的核心主线**（8 个任务用到），把它做成一个可复用的"清单/文档差异比对引擎"，就能覆盖大半项目。
- **但对比能成立的前提是文档能被准确解析成结构化数据**。PRD 里反复出现的真正技术难关是：
  1. **多格式文档解析准确率**：.doc / .docx / .xlsx / **PDF（认证报告，PRD 多次标注为技术难点）** 的结构化提取。
  2. **对比的规则化与匹配**：匹配键定义、归一化、interchangeable 规则、按位号比对等。
- 结论：**核心 = 文档结构化解析（底座）+ 规则化差异比对（主线能力）**。抓取/生成/归档/查询是围绕这条主线的配套能力。

## 六、需要优先去沟通/确认的对外事项（行动清单）

1. **PLM API 能力清单**（最高优先）：能否读字段、导清单、查 BOM/组件、反查机型、上传证书、读状态字段。几乎所有任务卡在这。
2. **集团档案室 API 开放**：任务 7 归档依赖，PRD 已点名需开放。
3. **SCP 13+9 计划接口**：任务 3d 判断退市尾单，PRD 标注待确认。
4. **飞书多维表格/云盘读写权限与接口**：任务 5、7、11。
5. **外部认证网站自动化可行性**：验证码 + UL 账号 + 反爬，任务 8b。
6. **零部件认证信息库样例**：任务 5 需要基准库文件（当前工作区缺失）。
7. **跨智能体交付物对接**：产品包结构化(李烨)、WBS 计划(闫伟玲)。

## 七、建议的推进主线

1. 先做**不依赖外部系统接口**、纯文档进出的任务打样：**3b 清单整合（已选）**、6 报告草稿核对——只需本地两/单文档，验证"解析+对比+生成+人确认+反馈"这套闭环。
2. 沉淀出通用的**文档结构化解析器 + 差异比对引擎 + 规则库/反馈闭环**。
3. 待 PLM/档案室/SCP 等接口谈通后，再接入依赖系统的任务（1、3d、7、8b、11）。

> 这样把"能自己跑的"和"卡接口的"分开，先用文档类任务把核心引擎打磨出来，接口就绪后横向复用。
