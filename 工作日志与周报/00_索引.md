## 关键结论速查

- **绝对地址转相对地址**：前端用 `base: './'` + `import.meta.env.BASE_URL` 统一 API 前缀，让一份构建产物适配子路径、8123 直连和跨网段中转代理（详见 `部署问题排查日志.md` 问题 22）。
- **跨网段访问**：中转 Nginx 做 `/certagent/` 前缀转发到 `10.18.87.51`，用户访问 `http://<中转IP:端口>/certagent/`，浏览器地址只出现中转 IP。
  - ⚠ **地址待确认**：桌面用户指南写 `10.19.98.208:4657`，排查经验文档写 `10.19.96.208:4657`，两处不一致，需向运维确认对外入口后统一。
- **数据正确性优先于模型能力**：行丢失、跨分组误匹配等问题在解析/比对层解决，不靠 Prompt。
- **LibreOffice 7.3 + systemd headless 不可靠**：改工作流（要求 .docx）比硬修转换器 ROI 更高。
