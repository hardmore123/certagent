## 与 20260730版本（v1）的差异
本版在 v1（A/B 角色定稿 + 方向2 + Web 前后端）基础上，新增**数据守恒审计**能力：

1. **LangGraph 审计节点 + 补录分支**（三.25）
   - 流程新增 `apply → audit → [条件边] → repair/memory`
   - 三层校验：引擎层(id引用) / 决策层(拒绝) / 物理层(回读docx)
   - critical 走 repair 补录到文档末尾「⚠审计补录」表，保证零物理丢失

2. **物理层按指纹自愈**（三.26）
   - 行指纹 `位号|关键件名称|型号|规格材料`（normalize 统一繁简/全半角/空白）
   - 多重集比对定位 writer 丢行，补录表列位对齐指纹，补录后重审可恢复 ok

3. **Web 落地**（三.27）
   - 后端 `apply_decisions` 跑 audit(+repair)，`/result` 返回 audit
   - 前端「审计面板」徽标 + 展开报告

4. **守恒等式可视化**（三.28）
   - 报告显示 A=同+异+A独、B=同+异+B独，带 ✓/✗

5. **UI 精简 + 语义更正**（三.29）
   - 上传标签更正：A=原始清单·旧版本，B=PLM·新品·新版本
   - 审计面板去花色、缩写、极简
   - 徽标名称改为「审计面板」
