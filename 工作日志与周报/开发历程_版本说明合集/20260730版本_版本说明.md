# Demo 版本快照 · 20260730

> 快照时间：2026-07-30
> 源目录：`list-merge-demo/`

## 本版本相对上一快照（demo版本一--2026.7.17）的主要演进

### 核心引擎（compare_core）
- **三级匹配 diff**：rich key → loose key → fuzzy name 前缀匹配（解决"电线组件"→"电线组件(0.5平方毫米...)"归组）
- **分趟匹配**：修复贪心顺序错配 bug（先全体 rich，再 loose，再 fuzzy），东芝样例 47 行从错配 CHANGED 修正回 SAME
- **A/B 角色翻转**：以 A（人工整理/新品）为遍历基底，输出骨架 = A 顺序
- **组级 diff**（`group_diff.py`）：按 (表号,分组,关键件名称) 聚合成 43 组，6 种状态，服务对照表归纳
- **比较字段加位号**：`compare_fields` 含位号，位号差异能被识别
- **纯 python-docx 解析**（`docx_parser.py`）：无 Word COM，线程安全
- **多级 .doc→.docx 转换**（`converter.py`）：LibreOffice / Word COM 子进程，主进程不碰 COM

### 对照表归纳（suggester）
- 组级 diff → 业务 5 类模板归纳，Mock / DeepSeek V4（Flash/Pro）均 5/5 覆盖
- 强约束 prompt（`group_summary.txt`）

### 输出（writer）
- ONLY_ORIG 不标红（A 独有保留项），ONLY_PLM / CHANGED 标红
- SAME 取 A 侧展示
- B 独有按 group 插入（当前粒度为分组标题，细化到关键件组的改进进行中）
- 来源标签：派生报告 / PLM / 两侧 / 两侧(差异)

### Web 前后端
- 后端 FastAPI（`webapi/`）：JWT 认证 + 异步任务 + 三级解析分派
- 前端 React+Vite（`frontend/`）：登录 / 工作台 / 差异确认页
- 差异确认页：CHANGED 行罗列所有字段 A/B 对比，差异字段高亮 + 词级高亮，白底

### LangGraph / 编排
- 三入口共用 `nodes.py`：CLI(core) / CLI(graph) / Web(runner 两阶段)
- 人在环 interrupt

## 快照排除项
- `node_modules/`（前端依赖，`npm install` 恢复）
- `runs/`（运行产物/缓存）
- `__pycache__/`、`*.pyc`
- `.env`（含 DeepSeek API key，安全起见不打包；参考 `.env.example`）
- `.kiro/`、`dist/`

## 恢复方式
```bash
# 后端依赖
pip install -r requirements.txt
# 前端依赖
cd frontend && npm install
# 配置
cp .env.example .env   # 填入 LLM_API_KEY
# 启动
python -m webapi           # 后端 :8000
cd frontend && npm run dev # 前端 :3000
```
