## 项目一：CertAgent（认证清单整合系统）

### 一、本半月结果产出

1. **服务器生产部署上线**：CertAgent 部署到 Linux 服务器（10.18.87.51），排查并清零 15 个部署问题（nginx ACL 权限、systemd HOME 缺失、LibreOffice 不可靠、端口统一 8123/8125）。
2. **加密文档上传打通**：解决透明加密（DLP）docx 上传即密文的问题，新增 `decrypt.py` 调解密服务还原 + 后端兜底 + 前端放行，明确三层处理策略。
3. **`/certagent/` 子路径部署跑通**：修复子路径下前端登录失败，前端改用 `import.meta.env.BASE_URL` 动态前缀；服务器端登录接口、首页入口、双入口均验证 200。
4. **拒绝策略 + 手动匹配 + 长期记忆闭环上线**：拒绝从二元丢弃升级为分类纠正；记忆库从“只写不读”变为按指纹聚合读回反哺建议。
5. **后台使用统计插件上线**：API 调用埋点落盘 + 管理端查询 + `check_stats.py`，已累积 14000+ 条记录。
6. **版本与文档沉淀**：推送 GitLab 4 个版本，补齐历史快照、排查日志、BLUEPRINT/DOCS/README/部署指南。

### 二、本半月具体工作

- **部署运维**：Linux 服务器全链路调通（Nginx 外层 `/certagent/` 代理 + 内层 8123 API + 后端认证）；构建产物改相对路径入口，解决浏览器缓存导致的 MIME 报错。
- **加密文件链路**：透明加密自动解密、Word 密码加密手动解除、.doc 另存为三条路径明确并落地。

## 项目二：报告草稿准确性核对（ReportVerify）

### 一、本半月结果产出

1. **需求5 立项 + 可行性方案**：确认与清单整合的核心差异（异类文档、目标是“核对”而非“合并”、批注+编号汇总、多轮审批），验证 `python-docx 1.2.0` 原生支持批注，锁定方案最大不确定点。
2. **初稿端到端跑通**：解析→定位→核对→批注→汇总链路打通，真实样本 A 923 行 / B 1074 行、核对差异 358 项、批注锚定 273 处。
3. **独立项目整理 + 行级差异视图**：作为独立 FastAPI 项目（端口 8010），改造为 CERT/DRAFT 双侧行级对比视图（SAME/CHANGED/ONLY_CERT/ONLY_DRAFT），新增 `/row-diffs` 接口，保留筛选、人工确认和下载门禁。
4. **核对规则细化**：占位符视为空、换行/分号/顿号等分隔符等价、忽略内部空格、修复“认证标准”列错位。
5. **可选 LLM 集成方案定稿**：完成 requirements/design/tasks 三份规格并通过格式校验，明确复用 CertAgent 模型/接口/凭据（受控注入不落库）、允许字段原文、图片硬拒绝、任务级开关。

### 二、本半月具体工作

- **样本分析与初稿**：解析海信认证资料（CERT）与认证机构报告草稿（DRAFT），产出可行性方案与 `report-verify-demo`（parser/differ/writer/pipeline + cli）。
- **行级视图改造**：新增 RowDiff 数据层与 `/api/jobs/{id}/row-diffs`，静态页面改为 CERT/DRAFT 并排行级视图，支持字段展开、待确认筛选、跳转与下载入口；19 项 unittest 通过、前端内联 JS 语法校验通过。
- **规则与解析修复**：确立“占位符/分隔符等价/忽略空格”归一化规则，修复第二张图的解析错位（认证标准列错位）。
- **LLM 集成规格**：完成技术设计（高层架构 + 低层接口）、需求与任务分解；确认使用 CertAgent 同模型/接口/凭据，允许字段原文，图片固定拒绝，允许任务级 LLM 开关；三份规格格式校验通过。
- **实现启动（已暂停归档）**：完成前置门禁 0.1（凭据映射/脱敏诊断，6/6 测试通过）与 0.3（CertAgent 协议本地 stub 契约，6/6 + 全量 40/40 通过）；0.2（服务器策略校验）执行中断，后续 1.1–4.15 未派发。
